{% comment %} One block of values on a compound card, forms.ValueBlockForm (as form), numbered by number, and by index from 0, as in its prefix, block-0: one line is a single value, several are a curve. A block left empty is skipped. Its first three boxes say what the values are of and against. The boxes those need (_block_boxes.html) are in the form only once all three read. Without JavaScript they appear after Check. With it, checks.js sends the card to views.check_block_boxes as soon as the choice changes (the row marked data-boxes names the boxes to replace, and they have the address). Under the points goes what the server makes of the block: its lines read, and a curve's chart (_curve_reading.html). Check fills it when the page comes back. checks.js fills it as the curator types anywhere in the block (data-check), with the block's problems listed first. It is a live region (aria-live), so a screen reader reads each new answer. {% endcomment %}
